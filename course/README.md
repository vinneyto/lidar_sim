# Практический курс: круговое LiDAR-сканирование 3DGS-сцены

За десять небольших задач вы соберёте второй эксперимент проекта —
`experiments/02_circular_scan.py`. Курс рассчитан на последовательное прохождение:
каждый следующий шаг использует результат предыдущего и знакомит с новым модулем
`gs_lidar`.

## Как проходить курс

1. Проходите каталоги `task_01` … `task_10` строго по порядку.
2. В каждой задаче допишите единственный блок `TODO` в `exercise.py`, сверяясь с
   готовым фрагментом в README только после собственной попытки.
3. Сразу запустите задачу командой
   `uv run python course/task_NN/exercise.py`. У каждого файла есть `main()`,
   который выполняет получившийся этап и печатает специфичный для него результат.
4. Тестов намеренно нет: консольный вывод и описанный в задаче результат служат
   ручной проверкой.
5. `exercise.py` следующей задачи уже содержит готовое решение предыдущей. Код
   намеренно дублируется: каждый этап является самостоятельной запускаемой
   программой, а не патчем к отдельному starter-файлу.
6. После десятого шага сравните результат с
   `course/reference/02_circular_scan.py` (это целевая версия эксперимента с
   явной функцией `main()`).

Для запуска нужны зависимости проекта (`uv sync`) и canonical Inria 3DGS PLY.
Укажите его в `PLY_PATH`. CPU доступен везде; `metal` требует macOS, Apple Silicon
и PyTorch MPS. Rerun откроет интерактивную 3D-сцену.

## Карта модулей

| Задача | Результат | Модули проекта |
|---|---|---|
| 1 | загрузка PLY | `loader`, `gaussian_cloud` |
| 2 | AABB и BVH | `gaussian_geometry`, `bvh` |
| 3 | выбор CPU/MPS | `simulator`, `cpu_tracer`, `metal_tracer` |
| 4 | круговая траектория | `lidar.LidarPose` |
| 5 | ориентация и лучи | `lidar.generate_rays`, `LidarConfig` |
| 6 | статическая сцена Rerun | `rerun_viewer` и публичные типы |
| 7 | временная шкала сканов | `scan.LidarScan` |
| 8 | диагностика результата | поля `LidarScan` |
| 9 | сборка симулятора | `LidarSimulator`, перенос `.to(device)` |
| 10 | цикл эксперимента | совместное использование всех модулей |

Курс не просит переimplementировать трассировщик. Его цель — понять контракты
готовых модулей и правильно соединить загрузку, ускоряющую структуру, позу,
конфигурацию, backend, результат и визуализацию.
